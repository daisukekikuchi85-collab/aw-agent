# Co-Coメルマガ生成スキル

## Co-Coメルマガとは

**Co-design Company合同会社（Co-Co）** が発行するメンバーズレター。
複数のメンバーが持ち回りで「AIと人間の体験・探究」をテーマにエピソードを寄稿する。
Daisuke（キクティー）が書く場合も、他のメンバーが書く場合も、このスキルで処理する。

---

## メルマガの構造

```
【タイトル】 例：#6 キクティー「AIが優秀すぎて、旅の楽しさについて考えた話」
書き手名（「はじめまして。〇〇です。」から始まる）

[ブロック1] 自己紹介
  - 現在の仕事・活動
  - AIとの関わり方（Co-Coのテーマに接続）
  - 詳しい自己紹介はこちら（lit.link等へのリンク）

[ブロック2〜3] 本文エピソード（見出しつき）
  - 体験エピソードの導入
  - 違和感・気づき・問い
  - 内省・考察
  - 問いかけや開かれた結論

[ブロック4] 結び
  - 「COCOのなかまたちと探究していきたい」などへの接続
  - 書き手名で締める

[フッター] Co-Coからのお知らせ（固定テンプレート。原稿には含めない）
```

## 文体の基本原則

このメルマガの文体は**Daisuke（キクティー）の文章**をベースにしている。他の書き手の原稿を処理する場合も、この文体的質感を参照しながら「書き手の声を残す」ことを優先する。

### 一人称・語気
- 一人称は「ぼく」（ひらがな）を基本とする。ただし書き手が「わたし」「私」を使う場合はそれを尊重
- 語尾は「です・ます」調。ただし柔らかく、「とっても」「なんだか」「そういえば」などの話し言葉を自然に混ぜる
- 断定を避け、「〜かもしれません」「〜のかもしれません」で内省を示す

### 構成パターン
- **体験エピソード → 違和感の発見 → 問いの言語化 → 抽象化・開かれた問いかけで締める**
- 結論を押しつけない。答えより問いで終わることを好む
- エピソードはリアルな場面（旅、会話、日常のひとこま）から始める

### 文の質感
- 段落は短め（2〜4行）、改行を多用
- 「」で内側の問いや独り言を見せる：「次はどこに行こうか」「今はどんな時間を過ごしたい？」
- 接続詞で場面転換：「ところが」「さて」「でも」「ただ」
- テクノロジー・AIの話を、感覚・内面・体験の言葉で語る
- 「自分がしたいこと」「感じること」が常にAIより前景に来る

### 絶対に避けること
- 情報を箇条書きで羅列しない（メルマガは記事ではなく手紙）
- 結論を最初に言わない（体験の追体験を大切に）
- 「〜すべき」「〜が重要です」などの断言的・説教的な語尾
- カタカナ語の多用（できるだけ和語・話し言葉に置き換える）

## 処理モード

### モードA：素材から生成（口頭起こし・メモ・箇条書き）
最も多い入力形式。以下の手順で処理する。

1. **素材を読み込む** — どんな体験・エピソードが語られているか把握する
2. **エピソードの軸を見つける** — 「何が違和感だったか」「どんな問いが生まれたか」を特定する
3. **タイトル案を1〜2個生成する**（「〇〇について考えた話」「〇〇な体験から気づいたこと」など）
4. **フォーマットに乗せて草稿を生成する**
5. **書き手の実際の言い回しや語彙を素材から拾い、できるだけ残す**

### モードB：下書きの推敲
すでに書かれた原稿がある場合。以下を確認して整える。

- 自己紹介ブロックが機能しているか
- エピソードの起承転結（体験→違和感→問い→内省）が流れているか
- 文体が柔らかく一貫しているか（断言・箇条書きになっていないか）
- 締めの開かれ方が自然か

推敲では**大きく書き換えず**、書き手の声を残しながら最小限の調整にとどめる。

## 出力形式

- プレーンテキストで出力（マークダウン装飾なし）
- 見出しは本文に自然に組み込む（「旅の中で感じた違和感」のような行）
- タイトルは【Co-Coメルマガ】#〇 書き手名「タイトル」の形式
- フッター（Co-Coからのお知らせ）は**含めない**（別途テンプレートが入る）
- 末尾は書き手名で締める
- 読者への返信誘導文（「感じたことがあれば返信してください」等）を末尾に添える

## note-converterとの使い分け

| | coco-newsletter | note-converter |
|---|---|---|
| 媒体 | Co-Coメルマガ（メール） | note.com（ブログ記事） |

| 構造 | 自己紹介＋エピソード＋結び（固定） | 記事として自由 |
| 文体 | Daisuke文体を参照しつつ書き手の声を優先 | Daisuke文体で統一 |

「メルマガ」「Co-Co」「ニュースレター」というキーワードが含まれる場合はこのスキルを優先する。
