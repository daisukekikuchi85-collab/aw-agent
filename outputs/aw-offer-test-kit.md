# AW法人向けオファー テストキット（オファーシート＋相手リスト＋反応記録）

目的：簡単なオファーを顧客にぶつけ、行動ベースの反応で選び直す。
前提：提供者は β・α に各1名。γ は提供者不在のためテストしない。★＝未検証。
顧客名・相手名はイニシャルで記録する。

---

## 1. オファーシート（4本）

テストの組み方：
- β1 と β2 は「買い手＝人事」をそろえ、「困りごと」だけを変える（どちらの問題設定が刺さるかを見る）
- α1 は買い手が違う（経営企画・幹部育成）。単独で反応を見る
- 入口は目的が違う（件数を増やせるか）。旗艦とは別に評価する

### β1 研修では変わらなかったリーダーに
- 誰に：人事部（リーダー育成担当）、事業部長
- 困りごと（買い手の言葉）：「あの人のこういうところ、なんとかならないか」。研修も面談もしたが変わらない
- 変化：本人が自分のパターンに気づき、自分から変わり始める。周囲が「最近ちがう」と言い出す
- 形態・期間：診断→個別の統合セッション→職場での実践→振り返り。期間は要確認（中外の実績をもとに設定）
- 価格帯：要確認（中外案件の単価を基準に仮置きする）
- 提供上限：年◯件（β担当者の稼働から算出。要確認）
- 検証したい仮説：「研修で変わらない個人」に予算を出す買い手がいる★

### β2 強みが裏目に出ている管理職に
- 誰に：人事部（労務・研修担当）
- 困りごと：成果は出すが、部下が疲弊する・辞める。指摘すると反発される
- 変化：責められずに、自分の強みが裏目に出るパターンを本人が理解する。部下との関わり方が変わる
- 形態・期間：β1 と同じ型。集合研修版（少人数）も選択肢として提示
- 価格帯：要確認
- 提供上限：β1 と共有（同じ担当者）
- 検証したい仮説：「ハラスメント予防」より「強みの裏目」という言い方のほうが、人事が社内で起案しやすい★
- 注意：被害者保護・事案対応とは切り分ける。事案後の当事者対応（元C1）はこのテストに含めない

### α1 AIの出力を判断し直せる幹部に
- 誰に：経営企画、DX推進、人事の幹部育成担当
- 困りごと：AIの出力をそのまま採用してしまう。却下・修正の判断ができる人がいない
- 変化：前提を問い直し、対立する見方を統合して判断できる幹部が育つ
- 形態・期間：まずパイロット1件（少人数・短期）。期間は要確認
- 価格帯：要確認（パイロットは実績化を優先し、条件を相談）
- 提供上限：年◯件（α担当者の稼働から算出。要確認）
- 検証したい仮説：三菱総研以外でも、この困りごとに予算がつく★

### 入口 変化への抵抗を「仕組み」として扱う半日セミナー
- 誰に：人事部、OD担当
- 困りごと：変革が進まない原因を「人のやる気」に帰してしまい、打ち手が尽きる
- 変化：抵抗を、本人を守る仕組み（免疫）として見立てられるようになる
- 形態・期間：半日セミナー（公開または社内）。録画・資料で、提供者の時間を増やさずに広げる
- 価格帯：要確認（入口なので低め）
- 提供上限：担当者は要確認。β・α の担当者の時間を食わない人・形にする
- 検証したい仮説：セミナー参加者から、β・α の相談が出る★

## 2. ぶつけ方（1回15〜30分）

1. オファーの1行だけを見せる（方法論の名前は出さない）
2. 3つ質問する
   - 「いま、これに近い困りごとはありますか。誰が困っていますか」
   - 「もし進めるとしたら、社内で誰が決めますか。予算はいつ組みますか」
   - 「次に何があれば、話を進められそうですか」
3. 相手の言葉をそのまま記録する（言い換えない。次のオファー文の素材になる）
4. 同じ相手に複数のオファーを見せる場合は、順番を毎回入れ替える

## 4. 反応の記録（行動ベース）

| レベル | 相手の行動 |
|---|---|
| 0 | 反応なし・断られた |
| 1 | 「面白い」「資料ください」（言葉だけ） |
| 2 | 次の打ち合わせが決まる／社内の別の人を連れてくる |
| 3 | 予算の時期・決裁者を教えてくれる／パイロットの条件の話になる |

記録欄：日付／相手#／オファー／レベル／相手の言葉（そのまま）／次の行動／担当

### 判断の目安（仮の基準）
- 各オファーにつき、まず5人にぶつける
- レベル2以上が2人以上 → 続行・磨く
- 全員レベル1以下 → 困りごとの言い方を変えて再テスト。2回続けば外す
- レベル3が出たら、提供上限と照らしてから次に進む（受けきれない約束をしない）
