## 執筆前の5項目・仮説

1. 想定読者の現在地：チームや事業を預かる立場で、朝の習慣術や生産性ハックを一通り試してきた。それでも忙しい時期ほど崩れ、そのたびに「もっと頑張らないと」と自分に言い聞かせている人
2. 読者の困りごと：方法は知っているのに、調子の悪い日にこそ使えない。いまの自分にどの方法が合うのか、見分けがつかない
3. 読前と読後の変化：読む前は「自己管理＝頑張って自分を律する一本道」。読んだ後は「状況に合う道を選び、効かなければ引き返すための地図」として見え、いまの詰まりが3層のどこにあるかを切り分けられる
4. 中心命題：セルフマネジメントは、頑張りを保つ技術ではなく、状況に合う道を選び直すための地図である。なぜなら、頑張りに頼る設計は頑張れない日に最初に止まり、どの場面でも効く単一の方法は見つかっておらず、効くかどうかは状況との相性で決まるから
5. 読後の次の一手：自分の詰まりを3層で切り分ける → 最初の小さな一手を試す → 予想と結果を見比べ、効かなければ手放す
