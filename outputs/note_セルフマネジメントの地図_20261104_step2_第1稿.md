# 頑張りに頼る設計は、頑張れない日に壊れる──セルフマネジメントの地図を描き直して見えたこと

忙しい週ほど、睡眠も、運動も、部下との対話も、いつもできていることから先に崩れていきます。そして「もっと頑張らないと」と、効かなかったやり方をさらに強めてしまう。

そんな経験に、心当たりのある方は少なくないかもしれません。

私は今、セルフマネジメントを一枚の地図にまとめる作業をしています。その地図を、研究リサーチに照らして点検してみました。

④ この地図の確度と、まだ白い場所
⑤ 実践編：3つの場面で使ってみる

## 頑張りに頼る一本道は、いちばん必要なときに使えなくなる

「セルフマネジメント」と聞いて、多くの人が思い浮かべるのは、我慢と自己規律で自分を動かす姿ではないでしょうか。朝のルーティンを守る。誘惑を断つ。感情は表に出さない。

手元のリサーチ資料は、この一本道に疑問を投げかけています。論点は2つあります。

**1つめは、「使うほど減っていく」という前提です。** 自制の力は使うほど減るとする「意志力消耗モデル（Ego Depletion）」は、再現性の問題が指摘されるようになりました。資料は、自分を律する力だけで統制し続けるやり方は、長くは続きにくいと見ています。

**2つめは、「回復のパラドックス」です。** 負荷が高く疲れている人ほど、仕事から心理的に離れる、しっかり休むといった回復の行動が取りにくくなる。そういう現象が報告されています。ただし、この現象を直接扱った研究は、資料の中ではまだ限られています。

たとえば、繁忙期の夜を思い浮かべてください。つい夜中までメールを見てしまい、眠りが浅くなる。翌朝は判断が雑になる。頭の中では「こんなときこそ気を引き締めないと」という声が出てきます。すると、さらに自分を追い込む方向に進んでしまいます。

ここで起きているのは、「自分が弱い」ということではないと、私は考えています。頑張りに頼る設計では、頑張れなくなった時点で、設計そのものが止まってしまう。これは資料の記述ではなく、私の解釈です。

では、頑張りに頼らない設計とは、どういうものでしょうか。

資料が示す方向は、環境の側に仕掛けを置くことです。望ましくない行動にはひと手間かかるようにしておき、望ましい行動は迷わず始められるようにしておく。集中したい日は、スマートフォンを鞄の底にしまう。翌朝走りたいなら、前の晩にシューズを玄関の真ん中に置いておく。疲れた自分の判断に任せず、疲れる前の自分が先に道を整えておく発想です。

もちろん、自分で自分に働きかけること自体が不要になるわけではありません。ただ、それだけを頼りにした地図には、「頑張れない日」の道が描かれていない。そういうことです。

## 地図を3つの層で描き直す

もともとの私の地図は、7つの領域でできていました。身体・エネルギー、感情・ストレス、注意・思考、行動・仕事、意欲・方向性、関係・コミュニケーション、周囲・環境。日常の言葉で、読者にも親しみやすいと考えていたものです。

リサーチの指摘は、率直でした。

- 並びの軸が混ざっている：身体は「からだの状態」、行動は「目に見える出力」、環境は「外の条件」。性質の違うものが同じ列に並んでいて、「何が起きているか」と「どこに働きかけるか」の区別があいまいになる
- 領域が重なっている：たとえば先延ばしは「仕事の進め方」の問題に見えて、頭の中で同時に抱えられる量（作業記憶）や、注意の配分の問題であることがある
- 抜けている視点がある：達成できなくなった目標から手を引くことと、勤務外の回復

そこでリサーチが代わりに提案したのが、「3層・6ドメインモデル」です。

| 層 | ドメイン | 見ているもの |
|---|---|---|
| 生体基盤層 | ① 生体生理・エネルギー回復 | 睡眠、呼吸、回復 |
| | ② 情動の覚知と受容 | 感情に気づき、言葉にし、否定せずに受け止める |
| 自己実行層 | ③ 注意・実行機能 | 限られた処理容量の配分と保護 |
| | ④ 目標の適応・行動の自動化 | 着手の仕組み、目標の手放しと立て直し |
| 環境・社会層 | ⑤ 環境設計・職務の構造 | 選択の環境、通知、仕事の組み立て |
| | ⑥ 関係・境界・援助要請 | 対人要求の調整、境界線、頼ること |

【Daisuke追記②：もとの7領域を描いたときの意図と、この再編案を読んだ実感。どこまで採用するか。「ぼくの理解では〜」「個人的には〜」で】

この地図の使いどころは、「行動が起こせない」といった問題が出たときに、原因を層ごとに切り分けられることです。

たとえば、重要な資料に朝から着手できないとします。昨夜の睡眠が足りていないのか（生体基盤層）。通知で注意が散っているのか（自己実行層）。机の上に別の案件が積み上がっているのか（環境・社会層）。「気が乗らない」とひとまとめにしていると、打つ手が見えません。

どの層の問題かで、打つ手が変わる。この地図で大事なのは、そこだと考えています。なお、この3層はリサーチが出した再編案で、確定した分類ではありません。

## 現在地は、頭の中だけでは測れない

地図があっても、現在地がわからなければ道は選べません。セルフマネジメントでいえば、「気づく」の段階です。

では、自分に意識を向ければ、自分のことがわかるのでしょうか。資料は、そうとは限らないとして、2つの研究を挙げています。

1つは、自分に向ける注意には2つの顔がある、という指摘です（Trapnell（トラプネル）& Campbell（キャンベル）、1999）。好奇心から自分を見つめる「内省」と、不安や脅威に押されて同じことを何度も考えてしまう「反芻」。外から見れば同じ「自分と向き合う時間」ですが、中身はまったく違います。

もう1つは、Wilson（ウィルソン）& Schooler（スクーラー）（1991）の研究です。「なぜそう感じるのか」と理由を言葉にして分析すると、言葉にしやすい表面的な理由に引っ張られて、選ぶものの質が下がることがある、というものです。

夜、ベッドの中で「なぜあの会議で、あんな言い方をしたのか」と考え続けてしまう。答えは出ないまま、眠りが遠のいていく。これが反芻の典型です。資料が勧める切り替えは、「なぜ」を「どの場面で、どのように」に変えること。「なぜ自分は無能なのか」ではなく、「どの発言のあとで、相手の表情が曇ったのか」を追います。

もう一つ、内側から見た現在地は、あてになりにくいことがあります。「自分は自分をわかっている」という感覚（内的自己認識）と、「周囲からどう見えているかをわかっている」度合い（外的自己認識）は、ほとんど関連しない。そういう指摘があります（Eurich（ユーリック）、2017）。からだの感覚でも似たことが起きて、疲れや緊張の「感じ」と、心拍などの実測値が一致しないことがあるといいます。

だから現在地は、頭の中の独り言だけでなく、外に目印を置いて読むほうがずれにくい、と私は考えています。目印の候補は2つです。安全な他者からの、行動についての定期的なフィードバック。そして、からだの客観的なデータ。ただし後者のウェアラブル機器による計測は、長い目で見て自己認識を高めるのか、スコアへの執着を生むのか、まだわかっていません。

もちろん、内省そのものを手放したいわけではありません。理由分析をやめるほうがよいのは、好みや経験に根ざした定性的な判断が中心の場面で、財務分析や法務のように厳密な検証が必要な場面は別だ、とリサーチは注記しています。

## 道は一本ではない。効かなければ引き返す

では、現在地がわかったとして、どの道を選べばよいのでしょうか。

手がかりは、Bonanno（ボナーノ）& Burton（バートン）（2013）の「調整柔軟性（Regulatory Flexibility）」です。いつでも効く万能の対処法を探すのをやめて、状況に応じて対処を切り替える力を、3つの要素で捉えます。

1. 文脈感受性：いま何が求められる状況かを読む
2. レパートリー：複数の打ち手を持っている
3. フィードバック応答：結果を見て、やり方を変える

地図で言い換えると、現在地を読み、複数の道を知っていて、歩いてみて道を変える、ということです。

道を選ぶ手がかりの一つは、制御できるかどうかです。制御できることには、問題解決や環境の設計で働きかける。制御できないことには、変えようとして消耗するより、その制約の中で何ができるかに目を移す。決定権のない全社方針の変更に不満を向け続けるより、「この条件で、自分のチームをどう守り、どう伸ばすか」に考えを切り替える、といった具合です。

そして、リサーチがもっとも重く見ているのが、効かない手を手放す段です。コーピング柔軟性（ストレスへの対処を状況に応じて変える力）の研究（Kato、2012・2020）は、「評価する → 中止する → 別の対処でやり直す」という流れを示しています。

もとのループは、「気づく → 見立てて選ぶ → 小さく動く → 観察して調整する → 学び、立て直す → 再び気づく」でした。リサーチは、ここに「手放す」という分かれ道を明示することを提案しています。

1. 気づく：からだ・感情・注意の状態と、置かれている状況を読む
2. 見立てる：制御できるかを確かめ、どの層に働きかけるかを決める
3. 小さく試す：失敗しても損の少ない最小の動きを、「もし〜したら〜する」の形で決める
4. 確かめる：試す前の予想と、実際の結果を見比べる
5. 分かれ道：効かなければ、自分を責めずに手放して仕切り直す。効いたら、日課や環境に定着させて、自分についての理解を更新する

そして、1に戻ります。

たとえば、1週間試してもメンバーに響かなかった指示の伝え方を、意地で続けずに撤回して、別の伝え方を試す。そのとき頭の中では「ここでやめたら負けだ」という声が出てくるかもしれません。資料はここで、撤回を「敗北」ではなく「資源を守る賢明な判断」と置き直すことを勧めています。

手放すことは、逃げと紙一重に見えます。リサーチは、代わりになる意味のある目標が視野に入っていることを条件にしています。行き先のないまま降りるのは、この地図の使い方ではありません。

## この地図の凡例と、まだ白い場所

地図には凡例があります。手元のリサーチ資料は、リーダーの日常に役立ちそうな50の介入原理を整理して、それぞれの確度をAからDで格付けしています。ここでいう確度は、資料側がつけた格付けです。

| 確度 | 意味 |
|---|---|
| A | 複数のRCT（参加者を無作為に分けて効果を比べる試験）、系統的レビュー、メタ分析で、効果が支持されている |
| B | 手法そのものではなく、背後にある仕組みに強い研究の裏づけがある |
| C | 隣接する理論や研究から、妥当な実践の仮説を導ける |
| D | 因果の証明は途上だが、リスクが低く、自己実験として試す価値がある |

資料はさらに、通俗的なビジネス書の定番のうち、掲載を推奨しないものも挙げています。感情を取り繕い続けること、「なぜ」を際限なく掘るジャーナリング、分刻みの厳格なタイムブロッキングなどです。感情を取り繕うやり方は、リーダー自身を消耗させ、部下からの見え方も下げうる、とされています。

そして、この地図には白い場所があります。

- 高い責任と裁量を持つ経営幹部だけを対象にした、大規模な介入研究は極めて限られています。多くの研究は、大学生、医療従事者、一般の成人、臨床の患者を対象にしています
- 仕事から完全に離れることが常に望ましいのかも、わかっていません。重大な案件を考えないようにすることで、翌朝の初動が遅れる可能性があります

つまり、「リーダーにも効く」と言い切れる手法は、多くありません。この記事で挙げた方法も、リーダーにも効く可能性が高い仮説という位置づけです。だからこそこの地図は、読んで終わりにせず、自分で小さく試して確かめる前提でできています。

## 実践編：この地図を現場で使う

「理論はわかった。では、現場でどう使うのか」

ここからは、この地図を使うとしたらどうなるか、場面ごとに書いてみます。

### ① 重要な仕事に、朝から着手できないとき

期限の近い企画書があります。机には向かっているのに、手が動かない。「気が乗らない」と片づけて、メールの返信を先に始めてしまう。

「着手できない」の原因は、ひとつとは限りません。3層のどこが詰まっているかで、打つ手が変わります。

- 生体基盤層：昨夜の睡眠や、ここ数日の回復はどうだったか
- 自己実行層：頭の中に、未完了のことが散らばっていないか。最初の2分でできる動作（ファイルを開いてタイトルだけ入力する、など）は何か
- 環境・社会層：通知や別の案件が視界に入っていないか。前の晩のうちに準備しておけることはないか

### ② 打ち手が効かないとき

1on1の進め方を変えて、1週間がたちました。メンバーの反応は変わりません。「もう少し続ければ効くはず」と、同じやり方を続けています。

続けるか手放すかは、気分ではなく、予想と結果のずれで決めます。効かなかった結果は、能力不足の証拠ではなく、地図の修正点です。

- 試す前に、どんな変化が起きると予想していたか。実際はどうだったか
- この件は、自分で制御できる範囲か。できないなら、その制約の中で何ができるか
- 手放すとしたら、代わりに試す道は何か

### ③ 夜や休日に、仕事が頭から離れないとき

金曜の夜になっても、来週の案件が頭の中を回っています。休日にチャットの通知が来て、つい開いてしまう。

疲れているときほど、自分の意思で仕事から離れるのは難しくなります。だから、疲れる前に仕組みへ預けておきます。ただし、完全に忘れることが常に最良かどうかは、まだわかっていません。

- 金曜の夕方に、持ち越す案件の「月曜の朝いちばんの5分の動作」を書き出す
- 休日の連絡の基準を、事前に合意しておく（例：緊急のときだけ電話）
- 個人のルールの前に、チームでの合意が先決なこともある

## 地図は、歩いた分だけ書き換わる

セルフマネジメントの上達は、手法が増えることではなく、地図の書き換えが速くなることだと、私は考えています。動けなかった日は、能力不足の記録ではなく、地図を書き換える材料になります。

最後に、問いを一つ残します。
