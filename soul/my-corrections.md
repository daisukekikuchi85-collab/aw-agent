# 用語・表記の統一ルール

音声入力やタイプミスで揺れやすい言葉を、正しい表記に直すための対応表。
**チーム全員がこの表を必ず守る。**

## 対応表

| こう入力されたら | こう書く | 補足 |
|---|---|---|
| 有理論 / ユー理論 | **U理論** | Theory U（オットー・シャーマー） |
| 計帳 / 慶弔 | **傾聴** | アクティブリスニング |
| 資材創発 | **知財創発** | 知的財産・無形資産の創出 |
| 上申発達 / 成人初達 | **成人発達** | 成人発達理論 |
| ヒューマネッセンス / ヒューマネセンス | **HUMANESCENCE** | 自社名。旧称 HUMERGENCE |
| グローセン / グロウセン | **グローセンパートナー** | 協業パートナー（Groesen Partner） |

## 育て方

自分の仕事で「いつも誤変換される言葉」に気づいたら、この表に1行足す。
次のセッションから全エージェントがその表記で書くようになる。

例:

```
| 自社の商品名の誤変換 | 正しい商品名 | 商品名なので必ず正確に |
```

固有名詞（社名・商品名・人名）は特に間違えやすいので、早めに登録しておくとよい。
